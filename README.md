## 📖 Tentang Aplikasi
**MGO Desktop** adalah sistem kasir (Point of Sale) profesional berbasis desktop yang dirancang khusus untuk memenuhi kebutuhan operasional kantor dan bisnis dengan mobilitas tinggi. Dibangun menggunakan ekosistem modern berperforma tinggi (**Tauri**, **React**, dan **Vite**), aplikasi ini menawarkan efisiensi luar biasa dengan ukuran file **kurang dari 10 MB**, konsumsi RAM yang sangat rendah, serta kestabilan dan keamanan server yang terjamin.

## ✨ Fitur Unggulan
- 🛒 **Transaksi Full Fitur:** Sistem manajemen kasir super lengkap untuk menangani berbagai skenario transaksi.
- ⚡ **Smart Caching System:** Menggunakan implementasi *cache* tingkat lanjut agar aplikasi tidak selalu *hit* ke database. Server dijamin aman, ringan, dan terhindar dari *overload*.
- 🪶 **Ultra-Ringan & Hemat RAM:** Berbasis Tauri dengan *native webview*, aplikasi berjalan sangat gesit dan ramah terhadap sumber daya sistem.
- 📦 **Ukuran < 10 MB:** Ukuran instalasi yang sangat ringkas dan efisien tanpa membebani penyimpanan perangkat.
- 🔄 **Realtime Synchronization:** Seluruh aliran data di dalam aplikasi tersinkronisasi secara langsung (*realtime*).
- 🎨 **Dark Mode & Kustomisasi Warna:** Dukungan penuh untuk mode gelap (Dark Mode) serta fleksibilitas untuk mengubah tema warna antarmuka sesuai selera.
- 📊 **Laporan & Export Excel:** Rekapitulasi penjualan komprehensif yang dilengkapi dengan fitur *Export to Excel* untuk kebutuhan audit.
- 📈 **Meteran Harian:** Pemantauan dan pencatatan metrik harian secara akurat.
- 👥 **Manajemen User Lengkap:** Sistem pengaturan hak akses (*Role-Based Access*) dan manajemen data pengguna yang sangat mendetail.
- 📁 **Manajemen & Cek File:** Integrasi sistem untuk pengecekan dan manajemen file operasional secara langsung.

## 💻 Persyaratan Sistem
Untuk menjamin kelancaran performa *realtime* dan efisiensi tingkat tinggi, perangkat keras yang dibutuhkan sangat minimal:
- **Sistem Operasi:** **Windows 10** atau yang lebih baru.
- **RAM:** Minimal **4 GB** (sangat hemat memori).

## 🛠️ Teknologi Inti
- **Tauri** - *Ultra-fast & Lightweight Cross-platform Framework (Rust-powered)*
- **React** - *Frontend UI Library*
- **Vite** - *Next Generation Frontend Tooling*
